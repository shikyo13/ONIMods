# Fast Insulated Self Sealing AirLock Continued

This is a community continuation of Neavo's Steam Workshop mod "Fast Insulated Self Sealing AirLock" for Oxygen Not Included.

## Credits And Provenance

- Neavo: original "Fast Insulated Self Sealing AirLock" Steam Workshop item.
- Tuna / mrcyclo: "Insulated Self-sealing Airlock", credited by Neavo as the base for Neavo's mod.
- EnemyArea, Davkas, Triggernometry: credited by Tuna on the source mod page.
- Chromiumboy and gbdickinson: related "Self-sealing Airlocks" lineage. gbdickinson's "Self-sealing Airlocks Revived" page explicitly welcomes active maintainers.
- 情深旧忆往昔: published an emergency compatibility fix for this mod, helped identify current community demand and compatibility reports, confirmed this continuation can carry maintenance forward, and updated their page to direct players here. Their workshop page is linked so players can find their other mods: https://steamcommunity.com/profiles/76561198928272072/myworkshopfiles/?appid=457140

## License And Permission Status

No explicit license file or source repository was found for Neavo's original mod.

Tuna's source repository is public at https://github.com/mrcyclo/ONIInsulatedSelfSealingAirLock, but no license file was found there.

This continuation preserves the original building prefab ID for save compatibility, uses a distinct mod static ID, and credits the known authors and references. If Neavo, Tuna / mrcyclo, or another prior author in this lineage requests changes, credit adjustments, or removal, this continuation should be updated, taken down, or redirected in favor of their continuation as appropriate.

## Save Compatibility

The in-game display name and mod static ID identify this as a continuation, but the saved-game building prefab ID remains `FastInsulatedSelfSealingAirLock`. Existing doors from Neavo's original mod should load as this continuation without replacement when the original mod is disabled and this continuation is enabled.
